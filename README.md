# 신뢰 게임 (리액트)

죄수의 딜레마 구조로 신뢰와 협력을 배우는 어울림 역량 수업 웹앱입니다. 1인 1태블릿 기준, 서버·데이터베이스·API 없이 동작합니다.

- 흐름: 시작(번호·장면 선택) → 규칙과 예측 → 경기장 지도 → 친구 카드 뽑기 → 5라운드 경기(3·2·1 카드 공개) → 마음 읽기·비밀 규칙 → STAGE CLEAR → 5명 모두 마치면 어울림 시상대 → 성찰 3문항 → 결과 복사(패들렛 제출)
- 장면: 체육 시간(함께 패스/혼자 슛), 모둠 활동(함께 나누기/나만 챙기기)
- 기록: 새로고침 대비로 그 탭의 sessionStorage에만 잠시 보관, 탭을 닫으면 사라짐
- 빌드: `npm install` → `npm run build` → `dist/` 폴더가 배포본 (vite `base: './'`)
- 미리보기용 파일 하나짜리: `npm run build:single` → `dist-single/index.html`
